# WeatherWise Frontend

React 19 + TypeScript + Vite tabanlı modern ve responsive hava durumu ve yaşam asistanı kullanıcı arayüzü.

## 🛠️ Teknoloji Yığını

- **React 19:** Modern React Hooks ve eşzamanlı render kabiliyetleri.
- **TypeScript (Strict Mode):** Tip güvenli veri akışı ve Pydantic API sözleşmesi eşlemesi.
- **Tailwind CSS v4:** Optimize edilmiş modern utility sınıfları ve mikro animasyonlar.
- **Lucide Icons:** Hızlı ve ağaç-sallama (tree-shaking) uyumlu vektör ikon kütüphanesi.
- **Vite:** Geliştirme sunucusu ve ters proxy (reverse proxy) entegrasyonu.

## 🚀 Çalıştırma

```bash
# Bağımlılıkları yükleme
npm install

# Geliştirme sunucusunu başlatma (http://localhost:5173)
npm run dev
```

## 🏗️ Üretim Derlemesi ve Doğrulama

```bash
# Tip denetimi ve üretim bundle derlemesi
npm run build

# Linter denetimi
npm run lint
```
